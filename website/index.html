01 / The system

More than an emulator.

Remote CP/M systems let callers use a computer over a modem. HUMONGOUS recreates that experience with a genuine CP/M 3 environment, carried over modern TCP connections.

[01] SYSTEM

A real CP/M prompt

CP/M 3 and Z3PLUS on z80pack. Explore named directories, run programs and discover classic command-line computing.

[02] ARCHIVE

Software worth exploring

Hundreds of historical user-group volumes, plus swappable libraries and optional software collections.

[03] COMMUNITY

Bulletin board

RBBS offers local discussion forums and private messages. Chat with the sysop using a split-screen interface.

[04] TRANSFER

Take software home

Classic file transfer protocols let callers download software and upload files to a writable work area.

[05] PLAY

Games from another era

Explore Adventure, Animals, Maze Chase and additional downloadable game libraries.

[06] SYSOP

Make it your own

Manage callers, access permissions and libraries from a local console while a remote caller uses the system.

03 / Getting started

Unpack. Start. Connect.

You can explore the board locally before opening it to other callers.

  1. Extract the native package into a writable folder.
  2. Run the supplied platform launcher.
  3. Connect a raw TCP terminal to 127.0.0.1:4000 and press Enter.

Read the included installation guide before exposing your board to the Internet. Keep SYSOP.DOC private.
